Recall from memory is keyed on the touch plus a summary of the episode so far, here the points where the hand released something it had carried 5 cm or more. Tested in the uncarded gate runs under working number 132 (no card is written yet). It lifts the with-cube AUC from 0.40 to 0.67, but the hand-written key is too noisy to reach the real-frame ceiling. [Card 134](../../experiments/134-unseen-state-from-effects/card.md) added the last effect of each object to that history: the content is present (a rule reading one item scores 90.3), but in a flat equal-weight key recall does not read it (57.9 against a bar of 88).
