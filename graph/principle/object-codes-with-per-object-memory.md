Represent the scene as one code per object, keep each object's recent history in a buffer, and predict the next codes through interactions between objects. In PLATO (Piloto et al. 2022) this gave expectations that objects persist and do not pass through each other, where one vector per frame did not. It was given the segmentation and tracking.
