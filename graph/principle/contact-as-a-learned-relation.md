title: Contact is the set of relative places of hand and object from which the object's latent state can change, learned with no rule
status: tested
links:
- rel: addresses
  to: problem/object-discovery
  basis: claimed
---
The relative place of an object's box and the hand's box (the gap along each axis, as one token of 36 values) enters the transition of the object's latent state ([events as latent state changes](events-as-latent-state-changes.md)) through a sparse coupling shared by all dynamics classes. "In reach" is the set of relative places from which "taken" is at least half as probable as from the best place. Tested in [card 159](../../experiments/159-contact-as-a-learned-relation-of-places/card.md): with true boxes it is exactly the simulator's rule in 10 worlds of 10; on the model's own boxes it is worse than a written rule, because objects bound by appearance are partial. Not adopted.
