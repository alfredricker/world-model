The recall key starts as "every item of the remembered contents counts equally" (each item scaled to unit spread over the store), and a small network may correct it only at a cost that shrinks with the number of stored events. With few events the key stays at the prior, so it is never more than 0.5 points below the prior alone; with 400 episodes it reaches 87.9% on pulls against 84.9% for the prior alone ([card 133.1](../../experiments/133.1-key-prior-corrected-by-evidence/card.md)).
