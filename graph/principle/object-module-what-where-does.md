The user, 2026-11-20: understand an object by its properties, so that it generalises to new positions and settings; use what serves from the Tolman-Eichenbaum Machine, modern Hopfield networks, AKOrN and CRAM. One module per object. Where: the place of the object's own frame. What: memories of stored patterns in that frame (shape, colour, and the individual's full pattern), each storing an input that nothing stored fits; the individual's pattern and the place of its frame settle together. Does: a belief over kinds, where a kind is a set of pairwise couplings between the tokens of a step (a shared set plus a sparse difference) and an object's kind is the set that predicts its records. Looks are coupled to kinds by pairwise couplings; an individual's own records are kept with its pattern and outweigh its looks. Tested in [card 152](../../experiments/152-an-object-module-that-knows-what-an-object-is-and-does/card.md). The rule that finds the kinds was the weak part; it is replaced by [one energy](kinds-by-one-energy.md) (card 153). Not yet tested: binding without true masks, rotation and scale, behaviour that depends on two attributes together.
