The user's question of 2026-11-19: can a token of the energy stand for an action (or a word). One step of experience is a set of tokens (the hand's effect, the action, and per object contact, held and effect); pairwise couplings between token values are learned by pseudolikelihood as in CRAM, with one action shared by every object of the scene. Clamping the state now and the wanted effect and settling the rest gives the action. First tested in [card 148](../../experiments/energy-modules/148-the-action-as-an-output-token/card.md) for single steps in the sprite world's simulator, against whole records stored in a modern Hopfield memory. Not yet tested: sequences, effects that depend on three tokens jointly, tokens that are not designed by hand.
