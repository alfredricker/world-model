In card 160's perceptron each code has its own output for staying as it is. Sharing one output for "no change" among all tokens was meant to make "this action does nothing here" carry across codes. Tested in [card 161](../../experiments/161-conditions-asked-of-the-effect-model/card.md), arm B: best in one experience, worse in the other two. Rejected as built; the cause is not known.
