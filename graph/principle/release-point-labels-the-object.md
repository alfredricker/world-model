The read-out that finds an object is trained on frames from before a touch, labelled with the contact point, and also on frames from after a touch, labelled with the release point, for touches at a group whose aim reading is switched on. The object is then found in places it was put but never picked up from ([card 143](../../experiments/143-found-where-it-was-let-go/card.md)). It does not hold for a slide as the data stand: the contact sensor stops reporting before the slide stops.
