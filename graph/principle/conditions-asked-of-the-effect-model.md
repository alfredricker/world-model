One model predicts every tick and answers the planner. When a plan wants an effect, the agent asks: with what is out of view now, will it happen? If not, would it happen with one of those tokens back in view? Then that token is brought back first. This replaces the list of tokens to avoid in a statement compiled in advance, which was stated only for a code that had itself been tried at least three times in that case ([acting by chaining learned statements](acting-by-chaining-learned-statements.md)). Because the network is shared by all codes, a condition learned on some objects applies to objects never tried in that case. Tested in [card 161](../../experiments/161-conditions-asked-of-the-effect-model/card.md): kept.
