On the 464 pulls whose lock was never touched but whose slide was pulled earlier, recall keyed on the touched object's own record, plus the records chosen by contrast, scores 90.3% balanced accuracy. Card 134's flat key scored 57.9 on the same pulls, the rule "same as the last pull of this slide" scores 90.3 and the true lock scores 91.9; the declared bar was 80. Nothing was trained and no rule was written: the key simply reads the item that decides. The weight is an estimate.
