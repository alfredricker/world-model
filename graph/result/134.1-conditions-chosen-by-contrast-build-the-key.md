A record is added to the key while it raises, by at least 1 point, the balanced accuracy of recalling whether the affected object changed, for stored episodes held out in turn. This added the drawer's lock for the drawer, the window's lock for the window and the cube for "drawer moves the cube", and never the other lock. On the 1,534 pulls with the lock touched earlier the key scores 95.3 against 88.5 for card 134's flat key and 95.9 for the true lock (bar 92). On the 198 reopenings it scores 94.0 against 93.4 for the flat key. The weight is an estimate.
