title: The recall key does not carry the episode so far
parent: problem/state-across-time
links: []
---
To predict what a reopened drawer holds, the agent must find the right remembered case, and the touch alone does not say whether the cube is inside. The key must also carry what has happened in the episode so far. Written by hand, that key is brittle. Learned, it needs many examples where remembering pays off, and the stored play data has only about 50 reopenings with the cube inside.
